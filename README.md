# ☕ Aplicação Java: Consumo de API (Desktop & Web)

Projeto desenvolvido em Java focado no consumo de APIs RESTful, apresentando duas interfaces de usuário: uma aplicação Desktop desenvolvida com **Java Swing** e uma interface Web.

---

## 🎯 Sobre o Projeto

O objetivo deste projeto é demonstrar a integração de serviços Web (APIs REST) em aplicações Java, aplicando conceitos de POO (Programação Orientada a Objetos), consumo e manipulação de dados JSON e construção de interfaces gráficas em dois ambientes distintos (Desktop e Web).

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Java (JDK 17+)
* **Interface Desktop:** Java Swing
* **Consumo de API:** `Javalin`
* **Gerenciador de Pacotes:** `Maven`

---

## 🏗️ Arquitetura e Recursos

* **Consumo de API REST:** Requisições HTTP (GET, POST, PUT, DELETE) e desserialização de JSON para objetos Java.
* **Módulo Desktop (Swing):** Interface gráfica responsiva para desktop com formulários, tabelas (`JTable`) e feedbacks visuais ao usuário.
* **Módulo Web:** Interface web para acesso e visualização dos dados via navegador.
* **Camada de Serviço Reutilizável:** A lógica de consumo da API é compartilhada entre os módulos Desktop e Web.
